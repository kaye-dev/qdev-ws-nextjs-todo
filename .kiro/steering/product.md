# プロダクト概要

AWS ECS Fargate へのデプロイを想定した Next.js ベースの Todo アプリケーションです。DynamoDB を使用した永続化ストレージを備えたシンプルなタスク管理インターフェースを提供します。

## 主な機能

- Todo アイテムの作成、読み取り、更新、削除
- タスクの完了状態の切り替え
- 視覚的なインジケーターによるリアルタイム進捗追跡
- ダークモード対応のレスポンシブデザイン
- コンテナオーケストレーション用のヘルスチェックエンドポイント
- AWS DynamoDB による永続化ストレージ

## ターゲット環境

- AWS ECS Fargate へのデプロイ
- Application Load Balancer によるトラフィック分散
- DynamoDB によるデータ永続化
- ワークショップ/学習シナリオ向けの複数参加者対応設計

## ユーザー体験

- タスク管理に特化したクリーンでミニマルなインターフェース
- ARIA ラベルとキーボードナビゲーションによるアクセシビリティ対応
- UI テキストの日本語対応
- Tailwind CSS によるモバイルレスポンシブデザイン
